Modern one-page demo

To run:

1. Install Node.js (14+).
2. In the project folder run:

   npm start

3. Open http://localhost:3000 in your browser.

What you'll find:
- `index.html`, `styles.css`, `app.js` implement a responsive, animated one-page site.
- `server.js` is a tiny static server used by `npm start`.

Customise tiles in `app.js` or the layout in `styles.css`.
